📞 SUPPORT & TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Panel doesn't open?
  → Check TextRefinePanel is rendered in editor
  → Verify useTextRefinement hook is called

API returns 400?
  → Check GOOGLE_GENERATIVE_AI_API_KEY is set
  → Verify Gemini API is enabled

Streaming not working?
  → Open DevTools → Network → look for /api/ai/refine-text
  → Check response type

Diff not showing?
  → Wait for refinement to complete
  → Check for API errors in console

See INTEGRATION_GUIDE.md for more troubleshooting.
